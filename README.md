# WP AI Engineering Blueprint

Reusable standards for building WordPress plugins and themes with Codex, ChatGPT, and other coding agents.

## Quick start
1. Upload this folder to a GitHub repository (private is fine).
2. Clone it locally or copy relevant instructions into each project.
3. Complete `specs/PROJECT_SPEC_TEMPLATE.md` as `specs/PROJECT_SPEC.md`.
4. Open the project in your coding agent and ask it to read `AGENTS.md` and relevant `docs/` files before coding.
5. Implement incrementally and run configured checks. Never deploy generated code without review.

## Contents
- `AGENTS.md`: persistent coding-agent instructions
- `docs/`: architecture, security, standards, testing and release guidance
- `specs/`: per-project requirements template
- `templates/plugin/`: starter-plugin design notes

This blueprint is a baseline, not a guarantee of security or correctness. Verify current APIs and directory policies against official WordPress documentation.
