# Release Checklist

- [ ] Correct metadata, version, license and dependencies.
- [ ] Readme/changelog and public APIs documented.
- [ ] No secrets, debug files or development-only artifacts in package.
- [ ] Supported WordPress/PHP versions tested.
- [ ] Security, privacy and permissions reviewed.
- [ ] Activation, upgrades, deactivation and uninstall behavior verified.
- [ ] Database migrations and rollback plan tested where applicable.
- [ ] Admin/frontend UX, accessibility and performance checked.
- [ ] Third-party services fail gracefully.
- [ ] Final report includes test results, known limitations and deployment notes.
